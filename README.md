This is a very small website that I made for a very small community, and you may be interested if you play Geometry Dash and are familiar with the concept of a Demonlist.
Basically, my friend is a small(ish?) content creator with his own Discord server, and as a part of this server, there is something I made called the "Wavelist."
The Wavelist progressed over time. It first started off as a simple project made on Google Sites, then I started adding more features, then this website happened because I thought it would be fun.
It was fun to make as well as really annoying at some times (account system, JavaScript file integration, basically anything that didn't involve keeping all the code inside one html file).
Just a heads up that this was intended for members of the Discord server, so if you plan on using this you should definitely join. There are links all over the site, you can't miss them.
If you want to see the origional Google Site out of curiosity, you can tag me in the Discord server (@saturndc47) and I will give you the link (it is still up).
Just keep in mind that the Google Site includes things like Google Forms for record and level submission, these forms do technically still work but this is not a valid way to submit records or levels.
It's a fun thing to check out but if you do try to submit records or levels from there you will be ignored because I don't check them anymore.

Anyway now that yap session is out of the way, I will keep an updating list of list editors in the readme, as well as their Discord names so you can contact them in the Discord server (they are all in the server).
I am the only website manager and the only person who has access to change any of the code, including the account database (hosted using Subabase) and the JavaScript file containing all the mainlist levels.
However there are still list editors that can decide on placements. These editors can simply talk with the other list editors and decide on changes together.
I personally take a very unbiased approach when it comes to this, so I do not proritize my opinion over anybody else's opinions simply because I am the only one with the power to physically make the change.
